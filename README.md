
# 🦶 Toe Bot

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)
![Discord](https://img.shields.io/badge/Discord-Bot-5865F2?logo=discord)

Official Discord bot for the TomoBao Server.

## Features

- Developer applications
- Alpha Tester applications
- Interactive Discord forms
- Persistent application buttons
- Staff approval system
- Automatic role assignment
- Private application logs
- SQLite database
- Cloud hosting support

## Commands

| Command | Description |
|---------|-------------|
| /ping | Check bot latency |
| /setup-applications | Create application panel |

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and configure
your bot token, server ID, channel ID and role IDs.

Start the bot:

```bash
python bot.py
```

## Cloud Hosting

Use a hosting provider that supports continuously
running Python applications and persistent storage.

Start command:

```bash
python bot.py
```

## Security and Privacy

Never publish your Discord bot token or application
database. Restrict access to application logs.

Inform applicants how their data is used and retained.
